# 龙之盔甲渲染修复

[English](./README.md) | [简体中文]

<p align="center">
  <img src="resources/Logo.png" width="450">
</p>

修复 [龙之研究](https://www.curseforge.com/minecraft/mc-mods/draconic-evolution) 1.7.10 Forge 龙之盔甲、双足飞龙盔甲颜色丢失的问题。

主要针对移动端，如 [Fold Craft Launcher](https://github.com/FCL-Team/FoldCraftLauncher)、[Zalith Launcher 2](https://github.com/ZalithLauncher/ZalithLauncher2)。

支持任意版本的龙之研究及其分支。

> 本模组为**客户端模组**，服务端无需安装。
